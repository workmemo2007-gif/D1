# موقع دايت فود — D1

هذا المستودع ينشر موقع دايت فود على GitHub Pages: <https://workmemo2007-gif.github.io/D1/>.

مصدر قائمة الطعام هو المستودع العام <https://github.com/workmemo2007-gif/J>. عند فتح الموقع، يحمّل `index.html` ملف `menu.json` وصور القائمة من ذلك المستودع. لذلك تُدار أسماء الأصناف وأوصافها وأسعارها وصورها في J، ولا يلزم تغيير HTML أو إعادة بناء صفحات GitHub Pages بعد كل تعديل محتوى.

يحتوي المستودع J على ملف البيانات في `menu.json`، وصور الأصناف في `images/products/`، والشعار وصور الغلاف في `images/brand/`. لا تضع أسراراً أو رموز وصول في هذا المستودع أو في J.
